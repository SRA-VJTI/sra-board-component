esp_err_t led_matrix_font_animate_text ( led_matrix_t *  matrix,
const char *  text,
uint32_t  character_delay_ms 
)

Reveal each character row by row, pulsing at intensity 15 for 40 ms and returning to the saved brightness for 70 ms after each row. Hold the character, then wipe it column by column. Wait character_delay_ms between characters and one second after the string. On failure, attempt to restore brightness and return the original error. Restoration failures are logged; the saved brightness is always preserved. Serialize access to the matrix while this blocking animation runs.

◆ led_matrix_chars

const uint8_t led_matrix_chars[LED_MATRIX_FONT_GLYPH_COUNT][LED_MATRIX_HEIGHT]
extern

8x8 glyph bitmaps indexed by ASCII value.

Printable ASCII (indices 32..126) uses a bold style; S, R, and A retain their existing display-specific designs. Glyph rows run top to bottom, with bit 7 as the leftmost pixel. Index 127 is blank.
